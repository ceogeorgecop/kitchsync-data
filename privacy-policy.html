แอปพลิเคชัน KitchSync (ผู้ช่วยจัดการวัตถุดิบในครัวอัจฉริยะ) พัฒนาโดย จ๊อด (ceogeorgecop) ออกแบบด้วยแนวคิด Offline-First (Guest Mode) ผู้ใช้สามารถใช้งานทุกฟีเจอร์หลักได้เต็มรูปแบบโดยไม่ต้องสมัครสมาชิก และมีตัวเลือกเสริม Cloud Sync (ผ่าน Supabase) เฉพาะผู้ที่ต้องการสำรองและซิงค์ข้อมูลข้ามเครื่องเท่านั้น แอปไม่มีโฆษณาติดตามตัว และไม่มีการขายหรือเปิดเผยข้อมูลส่วนบุคคลแก่บุคคลภายนอก

1. ข้อมูลผู้พัฒนาและแอปพลิเคชัน

นโยบายความเป็นส่วนตัวนี้ใช้กับแอปพลิเคชัน Android ชื่อ KitchSync (ผู้ช่วยจัดการวัตถุดิบในครัวอัจฉริยะ) (Package ID: com.jod.kitchsync) พัฒนาและดูแลโดย จ๊อด (ceogeorgecop)

2. การใช้งานแบบไม่ต้องสมัครสมาชิก (Guest Mode / Offline-First)

ผู้ใช้สามารถใช้งานแอป KitchSync ได้ทันทีโดยไม่ต้องลงทะเบียนบัญชี ข้อมูลทั้งหมดที่คุณสร้างและบันทึกจะถูกจัดเก็บไว้ภายในอุปกรณ์ของคุณเองเท่านั้น ได้แก่:

  • รายการวัตถุดิบในคลัง (ชื่อ ปริมาณ หน่วยนับ ราคา วันที่รับเข้า วันหมดอายุ และรูปถ่ายวัตถุดิบ)
  • รายการรหัสบาร์โค้ดที่บันทึกไว้เพื่อช่วยกรอกข้อมูลอัตโนมัติในครั้งถัดไป
  • สูตรอาหารส่วนตัว รายการโปรด (❤️) Note ซื้อของ ประวัติการใช้งาน และการตั้งค่าแจ้งเตือน
  • แคชรูปภาพและแพ็กสูตรอาหารที่ดาวน์โหลดเพื่อใช้งานแบบออฟไลน์

ข้อมูลในโหมดออฟไลน์ถูกจัดเก็บผ่าน IndexedDB (Dexie.js), Cache Storage และ SharedPreferences บนอุปกรณ์ของคุณเอง 100% โดยไม่มีการส่งขึ้นเซิร์ฟเวอร์ใดๆ

3. การลงทะเบียนผู้ใช้และการสำรองข้อมูล Cloud (Optional Cloud Sync)

หากผู้ใช้เลือกสมัครสมาชิกหรือเข้าสู่ระบบด้วยอีเมล (ไม่บังคับ) แอปจะเชื่อมต่อกับบริการ Supabase เพื่อยืนยันตัวตน (Supabase Auth) และสำรอง/ซิงค์ข้อมูลข้ามอุปกรณ์ โดยข้อมูลที่จัดเก็บบน Cloud ได้แก่:

  • อีเมลบัญชีผู้ใช้ (Account Email): ใช้สำหรับเข้าสู่ระบบและยืนยันตัวตนเจ้าของบัญชี
  • รูปโปรไฟล์ขนาดย่อ (Profile Avatar): เฉพาะกรณีที่ผู้ใช้ตั้งค่ารูปโปรไฟล์ (ย่อขนาดไม่เกิน 150×150px)
  • รายการคลังวัตถุดิบ (Inventory): รายชื่อวัตถุดิบ ปริมาณ หน่วยนับ ราคา วันหมดอายุ และสถานะการลบ
  • ความจำบาร์โค้ดส่วนตัว (Saved Barcodes): รหัสบาร์โค้ดและชื่อสินค้าที่ผู้ใช้บันทึกไว้
  • เมนูโปรด (Favorites): รายการสูตรอาหารที่ผู้ใช้กดหัวใจบันทึกไว้
  • การตั้งค่าแอป (App Settings): ภาษา ภูมิภาค ธีมสี และการตั้งค่าแจ้งเตือนวันหมดอายุ
🔒 ความปลอดภัยของข้อมูล: การรับส่งข้อมูลทั้งหมดระหว่างแอปและ Supabase ถูกเข้ารหัสผ่าน HTTPS (TLS) และจำกัดสิทธิ์การเข้าถึงข้อมูลในฐานข้อมูลเฉพาะเจ้าของบัญชีเท่านั้นด้วย Row Level Security (RLS) ไม่มีการขาย แบ่งปัน หรือเปิดเผยข้อมูลส่วนตัวของผู้ใช้แก่บุคคลภายนอกหรือผู้ลงโฆษณา

4. สิทธิ์การใช้งานที่แอปขอ (App Permissions)

KitchSync ขอสิทธิ์การใช้งานเท่าที่จำเป็นต่อฟีเจอร์ที่ผู้ใช้เลือกกดใช้งานเท่านั้น:

📷 กล้อง CAMERA

ใช้เฉพาะเมื่อผู้ใช้กดปุ่มสแกนบาร์โค้ด (ประมวลผลบนเครื่องด้วย Google ML Kit Barcode Scanning โดยไม่ส่งภาพออกนอกเครื่อง) หรือเมื่อผู้ใช้เลือกถ่ายภาพวัตถุดิบ/สูตรอาหารด้วยตนเอง

🎙️ ไมโครโฟน RECORD_AUDIO

ใช้เฉพาะเมื่อผู้ใช้กดปุ่มไมโครโฟนเพื่อเพิ่มวัตถุดิบเข้าคลังด้วยคำสั่งเสียง แอปไม่ได้บันทึกหรือเก็บไฟล์เสียงของผู้ใช้ไว้

🔔 การแจ้งเตือน POST_NOTIFICATIONS

ใช้สำหรับส่งการแจ้งเตือนภายในเครื่อง (Local Notification) เพื่อเตือนวัตถุดิบที่ใกล้หมดอายุหรือหมดอายุวันนี้ตามเวลาที่ผู้ใช้ตั้งค่าไว้

🌐 อินเทอร์เน็ต INTERNET

ใช้เมื่อผู้ใช้เลือกซิงค์บัญชีผ่าน Supabase Cloud, ดาวน์โหลด/อัปเดตแพ็กสูตรอาหารจาก GitHub Pages หรือค้นหาชื่อสินค้าจากรหัสบาร์โค้ดผ่าน Open Food Facts API

5. บริการภายนอกที่แอปเชื่อมต่อ

  • Supabase (supabase.com): ใช้เฉพาะเมื่อผู้ใช้สมัครสมาชิก/เข้าสู่ระบบ เพื่อยืนยันตัวตนและซิงค์ข้อมูลข้ามอุปกรณ์อย่างปลอดภัยภายใต้ HTTPS และ RLS
  • GitHub Pages (ceogeorgecop.github.io/kitchsync-data): ใช้สำหรับดาวน์โหลดไฟล์สูตรอาหาร รูปภาพอาหาร และตรวจสอบอัปเดตแพ็กสูตรอาหารเท่านั้น ไม่มีการส่งข้อมูลส่วนตัวของผู้ใช้
  • Open Food Facts API (world.openfoodfacts.org): ใช้ส่งเฉพาะรหัสบาร์โค้ดสินค้าเมื่อผู้ใช้สแกนบาร์โค้ดที่ยังไม่มีในเครื่อง เพื่อช่วยเติมชื่อสินค้าอัตโนมัติ
  • Google ML Kit (On-Device): ประมวลผลการอ่านบาร์โค้ดภายในอุปกรณ์โดยตรง

🛡️ Privacy Summary

KitchSync (Smart Kitchen Inventory & Recipe Assistant), developed by Jod (ceogeorgecop), is built with an Offline-First (Guest Mode) architecture. You can use all core features fully without creating an account. Optional Cloud Sync (powered by Supabase) is available only if you choose to sign up to back up and sync data across devices. KitchSync uses no ad tracking and never sells or discloses your personal data to third parties.

1. App & Developer Information

This Privacy Policy applies to the Android application KitchSync (Package ID: com.jod.kitchsync), developed and maintained by Jod (ceogeorgecop).

2. Guest Mode / Offline-First Storage (No Account Required)

You can use KitchSync immediately without registering an account. All data you create and save remains strictly inside your device's local storage, including:

  • Kitchen inventory items (name, quantity, unit, price, received date, expiry date, and item photos)
  • Locally remembered barcode-to-ingredient mappings for instant future scans
  • Custom recipes, favorites (❤️), shopping notes, usage history, and expiry alert settings
  • Downloaded recipe packs and cached food images for offline access

In Guest Mode, all data is stored 100% locally via IndexedDB (Dexie.js), Cache Storage, and Android SharedPreferences, with no data sent to any server.

3. User Account & Optional Cloud Sync (Supabase)

If you optionally choose to sign up or sign in with your email, KitchSync uses Supabase for authentication (Supabase Auth) and cross-device backup/sync. The data stored in your Cloud account includes:

  • Account Email: Used to authenticate your account and identify ownership.
  • Resized Profile Avatar: Stored only if you set a profile photo (resized to max 150×150px).
  • Kitchen Inventory: Ingredient names, quantities, units, prices, expiry dates, and sync/deletion timestamps.
  • Personal Saved Barcodes: Barcode numbers and product details you have remembered.
  • Favorite Recipes: Recipes you have marked as favorites (❤️).
  • App Settings: Language, region, theme, and expiry notification preferences.
🔒 Data Security: All data in transit between the app and Supabase is encrypted over HTTPS (TLS), and database access is strictly isolated to the account owner using Row Level Security (RLS). We never sell, rent, or share your personal data with third parties or advertisers.

4. App Permissions

KitchSync requests only the permissions required for features you actively choose to use:

📷 Camera CAMERA

Used only when you tap the barcode scanner (processed on-device using Google ML Kit Barcode Scanning without uploading camera frames) or when taking photos of ingredients/recipes.

🎙️ Microphone RECORD_AUDIO

Used only when you tap the microphone button to add ingredients by voice. KitchSync does not record or store audio files.

🔔 Notifications POST_NOTIFICATIONS

Used strictly for local on-device notifications to remind you about expiring or expired ingredients at your chosen daily time.

🌐 Internet INTERNET

Used when you opt into Supabase Cloud Sync, download/update recipe packs from GitHub Pages, or look up an unknown barcode via the Open Food Facts API.

5. Third-Party Services

  • Supabase (supabase.com): Used only when you sign up or sign in, providing secure authentication and encrypted Cloud Sync protected by HTTPS and RLS.
  • GitHub Pages (ceogeorgecop.github.io/kitchsync-data): Used solely to download recipe pack data, food images, and pack update manifests. No personal data is sent.
  • Open Food Facts API (world.openfoodfacts.org): When scanning an unrecognized barcode while online, only the barcode number is queried to look up public product names.
  • Google ML Kit Barcode Scanning: Runs locally on-device for fast, private barcode recognition.

6. วิธีลบบัญชีและข้อมูลถาวร (Account & Data Deletion)

ผู้ใช้มีสิทธิ์ควบคุมและลบข้อมูลทั้งหมดของตนเองได้อย่างถาวรทุกเมื่อ ทั้งข้อมูลบน Supabase Cloud และข้อมูลภายในอุปกรณ์:

📱 วิธีที่ 1: ลบบัญชีด้วยตนเองภายในแอป (ลบถาวรทันที)

เข้าเมนู "ตั้งค่า (Settings)" → การ์ด "☁️ บัญชีผู้ใช้ & สำรองข้อมูล Cloud" → กดปุ่มสีแดง "🗑️ ลบบัญชีและข้อมูลถาวร" และกดยืนยัน 2 ขั้นตอน

ระบบจะลบบัญชีผู้ใช้ (Auth Account) และข้อมูลทั้งหมดของคุณบน Supabase Cloud (คลังวัตถุดิบ บาร์โค้ดส่วนตัว เมนูโปรด รูปโปรไฟล์ และการตั้งค่า) ออกอย่างถาวรทันที ไม่ใช่การระงับชั่วคราว และไม่สามารถกู้คืนได้

✉️ วิธีที่ 2: ขอลบบัญชีจากภายนอกแอป (กรณีลบแอปออกแล้ว)

หากคุณได้ถอนการติดตั้งแอปไปแล้ว สามารถส่งคำขอลบบัญชีและข้อมูลทั้งหมดได้โดยติดต่อผู้พัฒนาผ่านอีเมล ceogeorgecop@users.noreply.github.com หรือแจ้งผ่าน GitHub Issues โดยระบุ อีเมลที่ใช้ลงทะเบียนในแอป KitchSync ผู้พัฒนาจะดำเนินการลบบัญชีและข้อมูลทั้งหมดออกจากระบบอย่างถาวรภายใน 7 วัน

  • การลบข้อมูลเฉพาะในเครื่อง (Local Data): คุณสามารถลบรายการในแอป ล้างข้อมูลแอปผ่านการตั้งค่า Android (การตั้งค่า > แอป > KitchSync > ที่เก็บข้อมูล > ล้างข้อมูล) หรือถอนการติดตั้งแอปเพื่อลบข้อมูลในเครื่องทั้งหมดได้ทันที

6. Permanent Account & Data Deletion

You have full control to permanently delete your account and all associated data from both Supabase Cloud and your local device at any time:

📱 Option 1: Self-Service In-App Deletion (Immediate & Permanent)

Open "Settings" → "☁️ Cloud Account & Backup" card → tap the red "🗑️ Delete Account & Data Permanently" button and complete the 2-step confirmation.

Your authentication account and all cloud records stored on Supabase (inventory, saved barcodes, favorites, profile avatar, and settings) are permanently deleted immediately — not temporarily deactivated — and cannot be recovered.

✉️ Option 2: External Deletion Request (If You Already Uninstalled the App)

If you have already uninstalled KitchSync, you can request permanent deletion of your account and all associated cloud data by emailing ceogeorgecop@users.noreply.github.com or opening a request at GitHub Issues from (or referencing) the registered email address used in KitchSync. The developer will permanently delete all associated account data within 7 days.

  • Local Device Data Deletion: You can delete items directly in the app, clear app storage in Android Settings (Settings > Apps > KitchSync > Storage > Clear Data), or uninstall KitchSync to remove all local data immediately.
